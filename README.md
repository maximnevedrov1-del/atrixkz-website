## Как опубликовать на GitHub Pages (бесплатно)

### Шаг 1. Создать репозиторий
1. Зайдите на [github.com](https://github.com) → Sign up (если нет аккаунта)
2. Нажмите **New repository**
3. Название: `atrixkz-website`
4. Выберите **Public**
5. Нажмите **Create repository**

### Шаг 2. Загрузить файлы
1. В новом репозитории нажмите **uploading an existing file**
2. Перетащите ВСЕ файлы из этой папки (или выберите через «choose your files»)
3. В поле **Commit changes** напишите: `Initial commit`
4. Нажмите **Commit changes**

### Шаг 3. Включить GitHub Pages
1. В репозитории перейдите в **Settings** (вкладка сверху)
2. В левом меню выберите **Pages**
3. В разделе **Source** выберите ветку `main`, папку `/ (root)`
4. Нажмите **Save**
5. Через 1–2 минуты сайт будет доступен по адресу:
   `https://ВАШ_НИК.github.io/atrixkz-website/`

### Шаг 4. Подключить свой домен (опционально)
1. В файле `CNAME` напишите ваш домен: `atrixkz.kz`
2. Загрузите файл в репозиторий (шаг 2)
3. В настройках DNS вашего домена добавьте запись:
   - Тип: `CNAME`
   - Имя: `@` или `www`
   - Значение: `ВАШ_НИК.github.io`
4. В GitHub Pages settings в поле **Custom domain** введите `atrixkz.kz`
5. Поставьте галочку **Enforce HTTPS**

## Что делает калькулятор

Калькулятор считает стоимость риска для 5 сценариев:
- **МРТ** — простой томографа + ремонт
- **Опасная пыль** — штрафы + ФОТ + лечение персонала
- **Клининг** — текучка кадров + прирост производительности
- **Типография** — простои печатных машин + сервис
- **IT/ЦОД** — ESD-разряд + простой системы

Клиент вводит свои цифры и видит, во сколько раз дешевле Atrix, чем один инцидент.

## Обновление сайта

Если нужно изменить текст или цены:
1. Откройте нужный `.html` файл в репозитории
2. Нажмите карандаш (✏️ Edit)
3. Внесите изменения
4. Нажмите **Commit changes**
5. Сайт обновится автоматически через 1 минуту
